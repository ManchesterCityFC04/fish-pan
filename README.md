# 摸鱼盯盘 · FishPan

> 为上班摸鱼而生的迷你悬浮窗 — 藏在屏幕角落，老板走过来一键隐身

一只小小的置顶窗口，放在屏幕角落，随时瞄一眼你的自选股。无边框、可拖拽、自动刷新，还带**隐身模式**和**价格提醒**——这才是摸鱼该有的装备。

## 技术栈

React 18 + TypeScript + Vite + Electron + sql.js (SQLite)

## 开发

```bash
npm install
npm run dev           # 仅启动 React 开发服务器（浏览器预览）
npm run electron:dev  # 启动 Electron 桌面窗口 + 热更新
```

## 打包

```bash
npm run electron:build  # 生成 .exe 安装包到 release/
```

## 功能

- 自选股实时行情（A 股 / 港股 / 美股）
- 涨红跌绿配色（A 股惯例）
- 无边框窗口 + 始终置顶
- 按住标题栏可拖拽到屏幕任意角落
- **两行紧凑卡片**，专门给屏幕角落小窗设计
- **点卡片看 K 线**：分时 / 1分 / 5分 / 15分 / 30分 / 60分 / 日K / 周K / 月K 多周期，自带 MA5/MA10 均线、成交量、十字光标与画线
- **大盘指数** 📊：上证 / 深证 / 创业板 / 沪深300 / 科创50 实时点位、涨跌幅、成交额
- **资金流** 💰：行业 / 概念 / 个股主力净流入排行（超大单·大单·中单·小单 + 领涨股）
- 5 秒自动刷新，可切换手动模式
- **SQLite 永久保存**：自选股与价格提醒存在 `fishpan.db`（用户数据目录），关掉重开、清缓存都不会丢
  - Windows：`%APPDATA%/fish-pan/fishpan.db`　macOS：`~/Library/Application Support/fish-pan/fishpan.db`

### 🐟 隐身模式（老板键）

按 **F9** 或点标题栏的 🐟，窗口瞬间伪装成「系统时钟 / 任务管理器」，老板以为你在看系统状态；
再按 F9（或点空白处 / 恢复按钮）立刻切回盯盘。隐身时数据仍在后台刷新，恢复即最新。

- 时钟皮肤：大号数字时钟 + 日期
- 监控皮肤：动态 CPU / MEM 占用条
- 隐身视图里点 🔄 可切换皮肤

### 🔔 价格提醒

每张卡片点 🔔 设置提醒，触发时弹 **系统原生通知**（不在电脑前也能收到）：

- 涨过价格 / 跌破价格
- 涨幅超过 % / 跌幅超过 %
- 提醒持久化，触发后标记「已触发」；点「重新武装」可再次监控
- 多个提醒同时生效，互不干扰

### 📈 K 线详情（精准源：东方财富）

点任意自选股卡片，进入 **K 线详情页**（窗口自动放大）：

- **9 个周期一键切换**：分时 / 1分 / 5分 / 15分 / 30分 / 60分 / 日K / 周K / 月K（前复权）
- 自绘蜡烛图 + 成交量柱 + MA5 / MA10 均线
- **十字光标**：鼠标移动显示 OHLC 读数（开高低收 + 涨跌幅）
- **画线**：点「画线」后左键点两点连线，右键撤销（趋势线辅助判断）
- 顶部显示实时价与涨跌幅，返回即回到盯盘列表
- 数据来自**东方财富**行情接口（更精准）；日/周/月若东方财富失败自动回退腾讯源

### 📊 大盘指数

点标题栏 📊 进入大盘视图（8 秒刷新）：

- 上证指数 / 深证成指 / 创业板指 / 沪深300 / 科创50
- 每行显示：实时点位 · 涨跌幅 · 成交额（亿）
- 涨红跌绿，一眼看清大盘冷暖

### 💰 资金流

点标题栏 💰 进入资金流视图（15 秒刷新）：

- 三个榜单：**行业 / 概念 / 个股**，按主力净流入从高到低排行
- 每行显示：名称 · 涨跌幅 · 领涨股 · 主力净流入
- 展开明细：超大单 / 大单 / 中单 / 小单 各自净流入（红=流入 绿=流出）
- 数据来自东方财富资金流接口，适合判断板块热度与主力动向

## 代码格式

| 市场 | 格式 | 示例 |
|------|------|------|
| A 股沪市 | `sh` + 6 位 | `sh600519` 或 `600519` |
| A 股深市 | `sz` + 6 位 | `sz000001` 或 `000001` |
| 港股 | `hk` + 5 位 | `hk00700` |
| 美股 | `us` + 代码 | `usAAPL` |
